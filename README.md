# VeriText AI – AI-Generated Content Detection & Analysis System

VeriText AI is an intelligent NLP and Deep Learning-based system designed to analyze text and identify whether it is likely to be **AI-generated or human-written**. The system supports text input as well as document uploads such as **PDF, DOCX, and TXT files**.

The project uses **Hugging Face Transformer models** for text classification and a **Python FastAPI backend** to process documents, extract text, perform AI-content detection, and return prediction results with confidence scores.

## 🚀 Key Features

* 🤖 AI-generated vs. human-written text detection
* 📄 PDF, DOCX, and TXT document analysis
* 🧠 Hugging Face Transformer model integration
* 🔍 NLP-based text preprocessing and analysis
* 📊 Confidence score and prediction results
* 📈 Chunk-based analysis for long documents
* ⚡ FastAPI backend for efficient API communication
* 🌐 Web-based frontend interface
* 🔗 Frontend–backend API integration
* 🛡️ Temporary file processing without permanently storing uploaded documents

## 🎯 Project Objective

The main objective of VeriText AI is to provide an accessible system for analyzing written content and estimating whether the content was generated by an AI system or written by a human. The project demonstrates the practical application of **Natural Language Processing, Transformer models, Deep Learning, and full-stack web development**.
